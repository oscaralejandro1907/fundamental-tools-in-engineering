The two operations

Multiply or divide — the result gets the fewest significant figures of any input.
Add or subtract — the result gets the fewest decimal places of any input.

Card 03

Rejection codes

  • UNIT MISMATCH — right idea, wrong quantity. Re-read what was asked.
  • UNVERIFIABLE PRECISION — you claimed digits you never measured, or threw away digits you had.
  • VALUE OUT OF RANGE — units and precision fine, arithmetic is not.
  • SIGNAL LOST — the window closed. A late number is no number.

Before you transmit

  • Did I convert every input to a consistent system first?
  • Which input has the fewest significant figures? That governs the answer.
  • Does the magnitude make physical sense for a small vehicle?
  • Is the unit in the dropdown the one the question asked for?

In the field

  • Repeat every run at least three times.
  • Write the raw reading down before you calculate anything.
  • Record the instrument, not just the number — "±0.2 s, human stopwatch".
  • Never silently drop an outlier. Note it and explain it.
Card 04 · for the teacher

Running an activity in class

Setup

  • One device per team of four, not per student.
  • Project the site on the room screen while teams play.
  • Works with no internet once the page has loaded.

During

  • Do not answer "is this right?" — the flight computer does that.
  • Do answer "what does this rejection code mean?".
  • Note which round most teams lose. That is your debrief.

After

  • Scores read aloud; the log table is the discussion material.
  • "Show the reasoning" reveals every explanation at once.
  • Close by mapping each round onto a real vehicle measurement.
